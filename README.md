# Dog Dog

`Dog Dog` is a NeoForge mod for Minecraft 1.21.1 that turns tamed wolves into real companions with personalities, names, growth, rescue mechanics, and more expressive behaviors.

这是一个围绕“养狗、陪伴、培养”展开的我的世界模组。每只被驯服的狗都会拥有不同的性格、名字、外观差异和成长路线，不再只是普通的狼。

## Features

- 13 种不同性格的狗狗，各自拥有独特行为与战斗风格
- 自动命名系统，支持玩家用命名牌自定义名字
- 亲密度、心情、透支组成的培养与羁绊机制
- 危重救助系统，狗狗受到致命伤害后仍有机会被救回
- 狗狗培养手册，帮助玩家了解性格特点和培养方式
- 寻宝、守护、治疗、救援等更丰富的陪伴玩法

## Environment

- Minecraft `1.21.1`
- NeoForge `21.1.70`
- Mod version `2.0.1`
- Java `21`

## Development

```bash
./gradlew build
```

在开发环境中也可以使用：

```bash
./gradlew runClient
```
